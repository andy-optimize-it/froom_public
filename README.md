# FROOM-public

FROOM-public contains materials describing the FROOM paradigm, a conceptual framework for deterministic architecture. The paradigm and its explanatory materials are public; the technology used to implement it is proprietary.

## Public paradigm, proprietary technology

This repository shares the FROOM paradigm, not its implementation. The runtime, operator machine, source code, and other implementation details remain proprietary. Access to or use of these public materials does not grant rights to the proprietary technology.
